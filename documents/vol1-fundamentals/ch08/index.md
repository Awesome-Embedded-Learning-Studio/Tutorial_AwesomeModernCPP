# 继承与多态

面向对象的威力在于"用统一的接口操作不同类型的对象"，而实现这一点的核心机制就是继承和多态。这一章咱们先立一个设计判断——继承还是组合、什么时候该用哪种；再从单继承的语法讲起，搞清楚虚函数表到底是什么、纯虚函数和抽象类怎么设计接口，然后看看多继承和虚继承的复杂度。最后通过一个实战案例把 OOP 的设计思路串起来。
