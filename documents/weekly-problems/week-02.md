### 第2题-解答题：逗号运算符与自增运算符问题(level 3 ~ level 4)：

```c++
int x;
int a = 10;
int b = 20;

x = (a++,b++);
//x等于多少？为什么？
//改成x = (a++,a++);又会发生什么事？
```

#### 参考答案：

x = 20

原因：(a++, b++) 是一个逗号表达式。逗号表达式的求值规则是：
先求左边 a++：
a 原来是 10；
a++ 的值是旧值 10；
a 变成 11；
但这个值 10 被丢弃。
再求右边 b++：
b 原来是 20；
b++ 的值是旧值 20；
b 变成 21。
整个逗号表达式的值等于最后一个表达式的值，也就是 b++ 的值，即 20。

变式：
改成x = (a++,a++);时是UB行为...吗？
——不是！哈哈，没想到吧~(其实作者也没有想到XD)
x = (a++, a++); 这个表达式的行为在 C 语言中是良定义（well-defined） 的，其求值顺序和正确性由 C 标准中关于逗号运算符（comma operator） 和序列点（sequence point） 的条款共同保证。核心条款位于 C11 标准（ISO/IEC 9899:2011）的第 6.5.17 节，同时 附录 C（Annex C） 也对序列点做了明确说明。
在CPP里也是良定义的，与C类似，此处不在赘述。

### 第3题-编写函数copy_n(level 2):

要求的函数原型如下：
void copy_n( char dst[], char src[], int n );
这个函数用于把一个字符串从数组src复制到数组dst，但有如下要求：必须正好复制n个字符到dst数组中，不能多，也不能少。
如果src字符串的长度小于n，你必须在复制后的字符串尾部补充足够的NUL字符，使它的长度正好为n。如果src的长度长于或等于n，那么你在dst中存储了n个字符后便可停止。
此时，数组dst将不是以NUL字符结尾。注意调用copy_n时，它应该在dst[0]至dst[n-1]的空间中存储一些东西，但也只局限于那些位置，这与src的长度无关。
//注：NUL字符就是'\0'

### 参考答案

```cpp
#include <iostream>

void copy_n(char dst[], char src[], int n);

int main()
{
    char src[] = "abc";
    char dst[10] = { '#' };  // 故意填非零值，观察是否被补齐

    for (int i = 1; i < 10; i++) dst[i] = '#';  // 全部填 '#'

    copy_n(dst, src, 5);

    std::cout << dst << std::endl;              // 应输出 "abc"
    for (int i = 0; i < 10; i++)
        std::cout << (dst[i] ? dst[i] : '0');   // 观察 dst[3]、dst[4] 是否为 '\0'
    std::cout << std::endl;
    return 0;
}

void copy_n(char dst[], char src[], int n)
{
    for (int i = 0;i < n;i++)
    {
		dst[i] = src[i];
        if (src[i] == '\0')
        {
            for (i++;i < n;i++)
            {
                dst[i] = '\0';
            }
        }
    }
}
```

### 最长平台问题(level 2)

已知一个已经从小到大排序的数组，这个数组中的一个平台（Plateau）就是连续的一串值相同的元素，并且这一串元素不能再延伸。
例如，在1,2,2,3,3,3,4,5,5,6 中 1,2-2,3-3-3,4,5-5,6 都是平台。
试编写一个程序，接收一个数组，把这个数组中最长的平台找出来。
在上面的例子中 3,3,3 (3-3-3) 就是该数组中最长的平台。
