# 卷 2 · 现代特性 练习与作业

## 这套练习解决什么

本卷各章都在「手把手带你走一遍」，但「看懂」和「做得出来」之间隔着一段路，这段路只能靠你自己走。这里是本卷的作业、实验与项目：每读完一章，Homework 有两道题趁热巩固；每读完一卷，Lab 用一条贯穿实验串起全卷，Project 用分层任务把全卷知识排练一遍。

所有题目遵循同一条原则：题面干净不剧透，参考答案单独成文件；每道题的解答一步步展开，每一步都标注它用到的知识点并链接回教材对应章节，卡住了随时顺着链接回原文补课。

## 三类作业：Homework / Lab / Project

**Homework（课后练习）** 按章出题，每章两道（基础 + 进阶），再加跨章综合与一道 L5 挑战。题目都做「变式」处理：换场景、换数据、换推理方向，照抄教材例题是抄不出答案的。

**Lab（动手实验）** 每卷一个，走「目标 → 步骤 → 命令 → 验收标准」的流程，通常五到六步，最后附一道挑战任务。它比 Homework 更接近真实工程：真开终端、真编译、真看输出，拿验收标准自己判断过没过。仓库自有的工程式 Lab（带 code/ 脚手架的里程碑实验，见卷 5）与本套的「实验题」互补——本套 Lab 侧重「真跑验证」，不要求脚手架。

**Project（综合项目）** 每卷一个，任务分四层：核心功能 → 进阶扩展 → 质量门 → 终极挑战。参考实现分文件逐段讲解，附真实运行输出。

## 五档难度

每份作业内部都覆盖全部五档，档位标注在每道题上。三份作业的整体难度依次递进：Homework 以 L1~L3 为主，Lab 以 L2~L4 为主，Project 以 L3~L5 为主。

| 档位 | 对标 | 出题风格 |
| --- | --- | --- |
| L1 | 全国计算机等级考试三级 | 计算机通识加基础编程，考「知不知道」 |
| L2 | 全国计算机等级考试四级 | 计组、操作系统、数据结构、软件工程综合风格，考「串不串得起来」 |
| L3 | CS61A→B→C 作业与 lab、408 真题 | 国外经典课程作业改编与考研真题风格，考「写不写得出来」 |
| L4 | SICP 练习、CSAPP 练习 | 深度机制分析（C++ 侧还有 Effective Modern C++ / Core Guidelines 风格），考「想不想得透」 |
| L5 | ICPC / IOI 等竞赛真题改编 | 挑战级，金牌难度。卷内口径：早期卷的 L5＝用本卷知识可解的最难问题；改编来源如实标注在题面 |

## 怎么用

先自己做完再对答案。卡住时先回题目标注的知识点链接读教材，读完再试；实在做不出来，再打开答案文件，从「解题思路」看起，逐步对照自己的思路错在哪一步——对到哪一步卡壳，就点哪一步的链接回去补。

所有答案代码都在 WSL（g++ 16 / clang++ 22，与教程同款）下真编译真跑过，验证输出全部真实；C++ 的未定义行为、内存与并发问题用 ASan/UBSan/TSan 实测。你的环境按本卷第 0 章搭好后，输出就应该对得上。
