# cookbook：卷五的速查区

正文教的是并发程序设计本身，概念、机制、设计与验证都在第一到第八单元的必修线上。cookbook 是另一本书，给已经懂并发概念、要知道 C++ 怎么写的读者：您来这儿不为学概念，为的是写代码时查一个 API 的准确用法，顺手避开常见的错法。所以配方不长，直给，读完就能贴进您的工程里试。

配方格式约定在 A 区执行得很死：每个配方一个问题加一段最小代码，代码全部实测（各篇标注编译器版本与标准选项），接着给要点与常见错误，末尾链回正文对应篇。配方是查表文，不是教程，机制的讲解归正文，配方只给用法、边界与错误形状，您要深挖就顺着链接走。

链回约定只有一条：配方末尾必挂正文对应篇的链接，篇名给全，位置交代到节。正文对应篇里若留了“归 cookbook 讲”的欠条，配方成文后就由咱们接上那一棒。

A 区是 API 配方，10 篇，见 [a-API/](a-API/)。mutex 家族与 RAII 锁、recursive 与 timed 变体、call_once、shared_mutex、多锁工具、jthread 停止协议、atomic_wait、atomic_ref、atomic_signal_fence、shared_future，您按名字查就行。

B 区是主题选读，整篇平移超出必修范围的内容，方向有九个：线程安全容器策略、无锁入门、SPSC 与 MPMC 无锁队列、教学级线程池、SeqLock 与自旋锁、异步 I/O 与事件循环、协程 echo server、Actor 模型、Channel 与 CSP，九篇全部住 [b-topics/](b-topics/)，您点进去就能读。
