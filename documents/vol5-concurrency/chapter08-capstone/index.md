# 第八单元：结课作品：一个小型任务处理程序

单元一到单元七，线程、共享、等待、任务、原子与协程各成一路，每一路都有配套的验收。第八单元咱们把它们合到一道题里：一个小型任务处理程序，生产者提交任务，工作线程执行，结果汇总，支持按条件停止。按节分篇：题目与行为要求立考卷，并发设计归您拿主意，完整的运行过程逐项收拢，交卷时附正确性检查与串行对比，另有协程综合扩展的选做。生产级线程池的要求、网络与日志的业务框架都不进必修，选读的正式入口还在迁移路上。
