# 并发世界观与第一件工具

咱们这一卷不从 `std::thread` 起手。多数教程一开场就领着读者开线程，咱们更愿意提前把思维方式立起来：为什么值得并发，出了问题长什么样。等两个问题都有了着落，后面的每一行并发代码才有判断力撑腰。写在卷首的三条原则——`先正确性再性能`、`先锁再无锁`、`先同步再任务`——往后每一章的取舍都照它们来，本章咱们就把它们逐条讲明白。

两篇的排法是这样。头一篇只用一条被阻塞卡死的主循环，把"为什么需要并发""并发与并行差在哪儿"讲清楚，再顺手掂一掂并行的收益上限，以及什么时候压根不该上并发。第二篇是工具第一课：数据竞争是并发里的头号杀手，咱们拿 ThreadSanitizer 当第一件工具，既学会读它的报告，也认清它的边界。至于开一条线程要付多少代价，那个数得动手量，咱们把量法放到了[第 4 章](../ch04-concurrent-data-structures/)开头的 OS 线程与开销篇，等您带着手感回去正好接上。

整卷的章节地图、练习体系与读法约定，都在[卷首页](../)上，迷路了就回那一页认位置。
