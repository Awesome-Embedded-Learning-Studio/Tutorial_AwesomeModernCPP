# Contributors

Thank you to everyone who has contributed to this project! Whether it's code, design, illustrations, bug reports, or content suggestions, your help makes this tutorial better.

## Contribution Types

| Icon | Type | Description |
|:----:|------|------|
| 🎨 | Interface Design | UI/UX design, visual polish |
| 🖼️ | Illustrations | Tutorial artwork, architecture diagrams, flowcharts |
| 🐛 | Bug Reports | Reporting errors via Issues, WeChat, QQ, email, and other channels |
| 📝 | Content Suggestions | Ideas for improving content and optimizing learning paths |
| 🔍 | Review | Content review and technical proofreading |
| 🌍 | Translation | English translation or translation into other languages |
| 💡 | Code Examples | Contributing code examples or improvement ideas |
| 📢 | Promotion | Helping spread the word about the project |

## How to Become a Contributor

We welcome contributions in every form! Including but not limited to:

- **Filing Issues**: spotting errors or inaccuracies
- **Content Suggestions**: topics you'd like to see added or improvement ideas
- **Interface Design**: UI/UX improvement proposals for the documentation site
- **Illustrations**: drawing diagrams and flowcharts for the tutorial
- **Translation**: helping translate tutorial content
- **Code Examples**: providing better code examples

Reach us through any of these channels:

- [GitHub Issues](https://github.com/Awesome-Embedded-Learning-Studio/Tutorial_AwesomeModernCPP/issues)
- Email: <725610365@qq.com>

See the [Contributing Guide](https://github.com/Awesome-Embedded-Learning-Studio/Tutorial_AwesomeModernCPP/blob/main/CONTRIBUTING.md) for details.
