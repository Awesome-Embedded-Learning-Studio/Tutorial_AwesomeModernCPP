# Volume 8: Domain Applications

> Status: Planned

## Overview

This volume covers practical applications of modern C++ across various domains, spanning seven sub-domains:

- **Embedded Development**: Resource constraints, zero-overhead abstraction, peripheral programming, RTOS, STM32 hands-on
- **Network Programming**: Socket, HTTP, asynchronous I/O, WebSocket, RPC
- **AI and TinyML**: Hand-roll a toy neural-network inference engine from scratch in modern C++, and understand how TinyML inference actually runs on an MCU
- **GUI and Graphics**: Graphics fundamentals, a minimal GUI framework, ImGui, 2D/3D rendering
- **Data Storage**: Serialization, file formats, SQLite, key-value storage
- **Algorithms and Data Structures**: Complexity analysis, classic algorithms, advanced data structures
- **C++ Deep Dives**: Deep dives into language mechanisms that span multiple domains (pointer semantics, weak reference design, and more)

An estimated 80 to 100 articles.
