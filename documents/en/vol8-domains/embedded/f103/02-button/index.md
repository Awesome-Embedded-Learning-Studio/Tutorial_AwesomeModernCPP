# Buttons: debouncing, state machines, variant

> Status: planned

## Overview

Buttons look simple — the traps are all in the timing: how to debounce mechanical bounce, how to tell a short press from a long one, how state transitions. This station manages the button lifecycle with a state machine and expresses button events with variant, so the type system watches every branch.
