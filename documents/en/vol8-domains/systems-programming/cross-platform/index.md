# Cross-Platform

Linux and Windows each have their own APIs, but at the end, there is a task that both sides cannot avoid: encapsulating differences into a single C++ abstraction. This is the task we complete in this section. When concluding the multiplexing chapter, we place epoll, kqueue, IOCP, and io_uring into a single matrix, and use C++20 concepts to define the shape of an asynchronous backend. The two chapters that conclude the entire volume are also here: detection, distribution, handle carrying, and the cost of dispatching are all incorporated into a single interface. The common tools used throughout the sub-volumes are compiled into four headers of syskit.
