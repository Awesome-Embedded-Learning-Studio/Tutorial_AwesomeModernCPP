# Lambda Expressions and Functional Programming

Lambda expressions are one of the most popular features C++11 introduced — they turned anonymous functions into first-class citizens and completely changed how we work with STL algorithms and callbacks. In this chapter we start from the basic lambda syntax, dig into the semantics and pitfalls of the capture mechanism, explore the template capabilities of generic lambdas, see how std::function and std::invoke work under the hood, and finally experience the elegance of higher-order functions, composition, and pipelines in functional programming patterns.
