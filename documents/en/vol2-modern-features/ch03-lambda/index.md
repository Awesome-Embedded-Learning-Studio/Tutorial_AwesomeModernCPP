# Lambda Expressions and Functional Programming

Lambda expressions are one of the most popular features C++11 introduced. They turned anonymous functions into first-class citizens and completely changed how we use STL algorithms and callbacks. In this chapter we start from the basics of lambda syntax, dig into the semantics and pitfalls of the capture mechanism, explore the template capabilities of generic lambdas, understand how std::function and std::invoke work under the hood, and finally put higher-order functions, composition, and pipelines to real use in functional programming patterns.
