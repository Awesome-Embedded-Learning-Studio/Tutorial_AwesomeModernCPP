# F407 + Renode 模拟器线

这条线全部跑在 Renode 模拟器里。您不需要买任何硬件,一台装了工具链的电脑就够了。

内容按外设铺开,每条外设走一条重构阶梯:从 C 裸机寄存器起步,一档一档升到类型安全封装、模板、C++23。每一档都用模拟器验证功能、用反汇编验证零开销。
