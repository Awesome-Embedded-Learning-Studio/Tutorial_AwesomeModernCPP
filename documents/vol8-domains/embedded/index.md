# 嵌入式开发

这条线讲现代 C++ 在嵌入式里怎么用对、用漂亮。和多数嵌入式教程最大的不同:**以 Renode 模拟器为主线**。您手头没有单片机,也能从头跟到尾,把每段代码跑起来、验证对。

目标芯片 STM32F407ZGT6(Cortex-M4F,带 FPU 和 DSP)。

## 三条轨道

- **[F407 + Renode 模拟器线](f407/renode/)** —— 现在的主线。纯模拟器,买不买板子都能学,这条线就是为没有单片机的朋友准备的。
- **[F407 真板线](f407/board/)** —— 以后补。同样的代码烧到真核心板上,对一下模拟器和实物一致不一致。
- **[STM32F103 线](f103/)** —— 基于 F1 的嵌入式 C++ 内容,和 F407 线平级维护。

## 怎么开始

直接去 [F407 + Renode 线的起步篇](f407/renode/00-getting-started/),装个 Renode,跑通第一盏灯。
