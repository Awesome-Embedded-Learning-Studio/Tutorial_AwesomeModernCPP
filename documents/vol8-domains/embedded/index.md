# 嵌入式开发

这条线回答一个问题:现代 C++ 拿到单片机上,到底该怎么用、能好到什么程度。主角是 C++,芯片是道具。所以整条线从门槛最低的 STM32F103 起步,一路走到资源宽裕的 STM32F407,同一套 C++ 打法在两块芯片上各走到头。

和多数嵌入式教程的另一个不同:**Renode 模拟器先行**。您手头没有单片机,也能把每段代码跑起来、验证对;真板验证放在每站的最后,有板子跟着做,没板子不耽误学。

## 两幕结构

- **[第一幕:STM32F103 + Renode](f103/)** —— 从点亮一盏 LED 开始,每个外设从 C 起步,一档一档重构到 C++23;每一档都用反汇编对照,证明抽象没有付出额外开销。
- **第二幕:STM32F407** —— 第一幕毕业后进阶:DMA、以太网、RTOS,再把整条线攒下的能力汇流成一个完整的大项目。

这条线正在按新结构逐步翻新,内容从第一幕的起步篇开始陆续上线。老版 STM32F103 教程(HAL 库起步)已归档,它的知识内核会融合进新线的对应站点。
