# 嵌入式开发

这套教程回答一个问题:现代 C++ 拿到单片机上,到底该怎么用、能好到什么程度。主角是 C++,芯片是道具。所以咱们从门槛最低的 STM32F103 起步,一路走到资源宽裕的 STM32F407,同一套 C++ 写法在两块芯片上各走到头。

和多数嵌入式教程的另一个不同:**Renode 模拟器先行**。您手头没有单片机,也能把每段代码跑起来、验证对;实际板子验证放在每站的最后,有板子跟着做,没板子不耽误学。

## 内容结构

- **[STM32F103 + Renode](f103/)** —— 从点亮一盏 LED 开始,每一站在一个外设上把现代 C++ 用起来:库里的轮子只讲不造,库里没有的自己写;反汇编对照,证明抽象没有额外开销。
- **STM32F407 进阶部分** —— 跟完 F103 之后:DMA、以太网、RTOS,再把攒下的能力汇流成一个完整的大项目。
