# 起步

动手装任何东西之前，先回答一个问题：单片机上凭什么用 C++？开篇用四份只有点灯写法不同的固件把"C++ 笨重""C++ 就是 OOP"两条旧印象上秤称掉——体积、指令、报错时机三个维度全是实测数字，您可以逐条复现。第二篇接着回答"这些坏印象是哪来的"：从 1979 年的 C with Classes 到九十年代的 EC++ 砍特性事件，史实全部带出处。

后续的开发环境、调试与工具链内容正在按新结构重写，写好一篇上一篇。
