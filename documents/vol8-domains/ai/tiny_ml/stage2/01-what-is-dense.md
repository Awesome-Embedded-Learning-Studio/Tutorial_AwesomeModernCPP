# Dense 在算什么——一次乘加,拆到每个输出

[Stage 1 的 02 篇](../stage1/02-tensor-in-neural-network.md)拆 Dense 层手边那四种 Tensor 的时候,故意留了个坑:权重和输入到底怎么乘起来再加好,是 Stage 2 的活。这篇就来填这个坑。

先把 Dense 这个名字祛个魅。它中文叫"全连接层",英文 Dense 直译"稠密",说的是同一件事:这一层的每个输出,都跟所有输入连着。"全连接"就是"全连上了",一个输入都不落下。所以它干的事,你猜也猜得到——把所有输入掺一块儿,揉成几个输出。

具体揉法,就一个公式:

```text
y = W·x + b
```

整体看有点抽象,咱们拆到单个输出上看就清楚了。

## 拆到第 0 个输出

拿咱们这个 Lab 的第一层 `Dense(3, 4)` 当例子:3 个输入(温度、湿度、光照),揉成 4 个中间值。输入 x 是长度 3 的向量,输出 y 是长度 4 的向量,权重 W 是一张 4×3 的表——这些形状 [Stage 1 的 02 篇](../stage1/02-tensor-in-neural-network.md)摆过,这里不重复。

光看第 0 个输出 y[0] 是怎么来的。它把 3 个输入各自乘个系数,再加起来,最后补一个常数:

```text
y[0] = W[0,0]·x[0] + W[0,1]·x[1] + W[0,2]·x[2] + b[0]
```

这里 `W[0,0]`、`W[0,1]`、`W[0,2]` 是权重表里**第 0 行**那三个数,正是 [Stage 1 的 02 篇](../stage1/02-tensor-in-neural-network.md)说的"算第 0 个输出用的那组配方";`b[0]` 是偏置里第 0 个常数,那个"混完之后整体抬一下"的推子。三个输入各按各的比例掺好、加起来、再抬一下,就是 y[0]。

剩下的 y[1]、y[2]、y[3] 一模一样,只是各自用权重表的第 1、2、3 行:

```text
y[1] = W[1,0]·x[0] + W[1,1]·x[1] + W[1,2]·x[2] + b[1]
y[2] = W[2,0]·x[0] + W[2,1]·x[1] + W[2,2]·x[2] + b[2]
y[3] = W[3,0]·x[0] + W[3,1]·x[1] + W[3,2]·x[2] + b[3]
```

规律摆出来了:每个输出对应权重表的一行,那一行的每个数乘上对应的输入,加起来,再补自己的偏置。一个 `Dense(3, 4)`,就是 4 个这样的加权和并行算出来。

## 一句话:Dense 就是 Out 个加权和

把上面这个规律提炼一下。一个 `Dense(In, Out)`,产出 Out 个输出,第 o 个输出是:

```text
y[o] = Σ W[o,i]·x[i]  +  b[o]        (i 从 0 到 In-1)
```

就这一行。权重的第 o 行 `W[o,:]` 决定"算第 o 个输出时,每个输入按多少比例掺";偏置的第 o 个 `b[o]` 决定"掺完整体抬多少"。Out 个输出,就是 Out 组这样的配方各自算各的。

所以 Dense 层说白了是个"批量算加权和"的机器:你给它 In 个输入和一张 Out×In 的配方表,它还你 Out 个加权和。神经网络"学"的东西,学的就是这张配方表里的数——训练阶段不断调 W 和 b,直到揉出来的输出能正确判断设备状态。

## 这里还不碰激活

你可能注意到,上面全程没提 ReLU、没提"负数归零"那档子事。这是故意的。一个完整的 Dense 层在神经网络里通常是"仿射 + 激活"两步:先做 `W·x + b`(仿射,就是这篇讲的乘加),再把结果丢给一个激活函数(咱们用 ReLU,把负数归零)。

咱们把这两步拆开:Stage 2 只造仿射这一半,`Dense` 类只管 `y = W·x + b`;激活留到 Stage 3,单独造个 ReLU。这样每一步只对付一个新概念,Dense 的实现不至于被激活的细节搅浑。所以接下来你看到的 `Dense::forward`,吐出来的是"仿射之后、激活之前"的原始值,负数还留着,Stage 3 再来收拾。

## 带走什么

这篇拆完了 Dense 在算什么,你记住三样就够:Dense 层产出 Out 个输出,每个输出是所有输入的加权和(权重的一行乘输入,逐个相乘再相加);每个输出再加自己的偏置;激活不在这层的活儿里,留到 Stage 3。

公式 `y = W·x + b` 现在不该再是一坨抽象符号了,它就是 Out 个加权和的缩写。但这里有个细节咱们一笔带过了:权重那张表的"第 o 行",在内存里到底怎么摆?为什么非得是 Out 行 In 列、不能反过来 In 行 Out 列?这事看着像抠细节,其实牵扯到 cache 性能和 Stage 5 跟 NumPy 对拍能不能对上。[下一篇](./02-weight-shape.md)就专门拆它。
