# 崩溃实验室:错误在这里,崩在那里

嘿！欢迎来到笔者的小巧思环节。我说我在查一个软件的子模块的崩溃问题而差点崩溃的时候，突然有一个点子。我说这个世界上，好像还真没有专门，专门讲解崩溃排查的cases。尽管我们总是说——嘿朋友，您应该挂上您那该死的GDB调试器，跟我一起看那没头没尾的不知道崩到什么B地方的堆栈上去。这就是排查崩溃。

他们的原因，负责的说，可以从单纯的简单，也就是纯自己脑抽了访问了释放对象，到回调访问失效对象，时序间隔访问空指针，在神秘时刻突然访问了释放的对象而其他引用没有置空。。。随便的说都是C++中常见导致崩溃的原因，我都见过。

我希望这一系列的内容，可以分享一下我作为一个一般路过的C++开发者在自己实际开发中遇到的一些崩溃类型，方便各位之后在实际的，其实不管是C，还是C++，都能写出来崩溃少一些的代码。
