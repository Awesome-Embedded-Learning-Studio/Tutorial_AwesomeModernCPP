# 加入交流

咱们有了读者交流群：读到哪里卡住了、想吐槽某篇写得绕（部分内容也有 LLM 参与，但是我们在持之以恒的减少他们！）、或者单纯想找人聊聊 C++，都欢迎进群。

<QQGroupCard />

## 各渠道分工

- **QQ 群**：快速提问、日常闲聊、催更反馈，随口就来。
- **GitHub Discussions**：开放式讨论——路线建议、学习心得、值得展开聊的话题。
- **GitHub Issue**：明确的内容提案、投稿主题、错误报告。
- **Email**：<725610365@qq.com>，适合不方便公开聊的事。

有价值的讨论建议留在 Discussions 或 Issue 里——那边方便沉淀和检索，不会沉进聊天记录找不着。
