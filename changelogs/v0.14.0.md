# v0.14.0：并发卷重写、ZerOS 十站走完的一个版本！(2026-11-23)

> 这一个月,卷五推倒重写了一遍,手搓 ZerOS 也从空仓库走到了 v0.1.0。

v0.13.0 之后攒下来的二十个 commit,一千一百七十一个文件变动,十一万八千行新增,五万四千行删除。删除的大头是卷五的旧稿,中文一份英文一份,占了删除量的八成。这一版的主线是重写:卷五并发编程按「七关加 cookbook」的结构重新写了一遍,手搓 ZerOS 的十个站点全部上线,F103 教程补上按键、UART、时间三站。

主要是这些：

- 手搓 ZerOS 十个站点全部上线,这一版补了后八站二十二篇,从超级循环一路写到 v0.1.0 发布
- F103 嵌入式教程补上按键、UART、时间三站,再加日志组件一篇,十篇中英同步

- 社区勘误五处,两处示例原样编译不过的问题由 PR 直接修好

## 卷五并发编程:推倒重来(#334)

旧版十章加 exercises 整体下线。新版按「关」组织,每一关回答一个设计问题,API 跟着问题出场:

- **第一关·让程序开始并发执行**:十篇,从主频停滞讲到第一个 std::thread,再到 jthread 与协作式停止
- **第二关·多个任务怎样共同使用数据**:七篇,从两条线程算错一个计数器讲到锁的范围、接口漏锁、死锁防线
- **第三关·任务之间怎样等待和协调**:七篇,条件变量、notify 与超时、有容量的队列、关闭与背压、异常安全
- **第四关·从管理线程走向组织任务**:四篇,std::async、启动策略、promise 与 packaged_task
- **第五关·理解原子操作与内存模型**:五篇,CAS、happens-before、内存序四档,最后拿停止标志、引用计数和 DCLP 练判据
- **第六关·怎样判断并发设计是否有效**:五篇,TSan、停止路径测试、基准工具与规模、粒度、线程数三个变量
- **第七关·用协程表达可以暂停的工作**:八篇,最小协程、co_await、教学版 Task、调度器,最后两篇选读拼出 Epoll IOManager 和 Echo-Server

**cookbook 是另一本书**,给已经懂并发、只想查 C++ 怎么写的朋友。A 区 API 配方十篇:mutex 家族与 RAII 锁、recursive 与 timed 变体、call_once、shared_mutex、多锁工具、jthread 停止协议、atomic_wait、atomic_ref、atomic_signal_fence、shared_future,每个配方一个问题加一段最小代码,末尾链回正文。B 区主题选读九篇:线程池、无锁队列、SeqLock 与自旋锁、异步 I/O 与事件循环、Actor、Channel 与 CSP 这些超出必修线的内容整篇搬到这里,旧版 ch04 的无锁队列、ch05 的线程池、ch06 的 echo server、ch07 的 Actor 和 CSP 都在新家。

**新组件 `<ConcurrencyTimeline>`**:并发教学用的时间线图,行是执行者(核心或线程),列是时间段,格子是工作段,鼠标悬停整列高亮,用来看「同一小段时间里谁在干活」。纯 Markdown 阅读器里降级成 mermaid 静态图,站点上也能切到「看静态图」。

**打标是诚实的**:卷五六十五篇里五十六篇挂着「正在进行打磨」的状态标,说明里写的是「现在是 LLM 写好的初级稿件,引入是为了初步公开 + 希望收集反馈」。卷首的说明写得很直白,欢迎带上 LLM 来锐评。

实验全部收在 `code/examples/vol5/`,一百九十一个文件按章分目录,页面上的在线示例点开就能跑。原实验在 GCC 16.2.1、WSL2 下实测,涉及标准库行为的查过 cppreference 和 eel.is 上的现行草案,条款链接收在各篇参考资源里。

旧版的 exercises 九篇和「从并发到分布式」两篇这次没有保留,项目页上「迷你并发运行时 capstone」的条目也一并撤下。卷五的目录名全换了,旧链接会 404,404 页加了一句提示指回总站。

## 手搓 ZerOS:十个站点全部上线(#322 与后续打磨)

v0.12.0 的时候这条线只有前两站。这一版把后八站二十二篇一次补齐,文章锚定仓库真实的 26 个 commit,同一份内核在 host 单测、Renode 仿真、QEMU mps2-an385 和真正的开发板四个环境里验证。

- **给内核一秒钟:时间与临界区**(两篇):tick 类型与回绕算术、到期队列,SysTick 优先级的真相,临界区从 CMSIS 宏换到内联汇编
- **CPU 归谁:从就绪位图到中断唤醒**(四篇):就绪位图与选人仲裁,PendSV 第一次切换,丢失唤醒与 typestate,中断唤醒
- **正确的等待:计数信号量与优先级继承**(两篇)
- **谁的上下文:遗言、底半与定时器**(三篇):fault canary 与日志、消息队列与 worker、软件定时器与回调
- **公平与收束:时间片、事件组与直接通知**(两篇)
- **demo 注册中心与 CI**(两篇)
- **真硅秒表:切换到底多贵**(三篇):时钟树与 DWT 第一次测量、RAM 函数回滚实验、无 tick 变体
- **第二块板与出门:QEMU、tickless、v0.1.0**(四篇):QEMU mps2 第二块板、栈水位、tickless 空闲、v0.1.0 发布

卷首的「跟读姿势」直接写明了一件事:个别中间 commit 在 host 上是编不过的,接口在前、实现在后是真实的开发节奏,对应的文章会写明 checkout 到哪个 commit 才能跑绿。

上线之后笔者又回头把时间内核和调度器开头几篇打磨了一轮,段落结构理顺了,「正在进行打磨」的状态标也摘了。

## F103 教程:按键、UART、时间三站(#317)

- **按键站两篇**:同一根 PA0 接进两条链,轮询消抖对拍 EXTI 边沿。回调从弱符号换成 concept 约束,两代写法摆在一起看
- **UART 站两篇**:阻塞收发的命令控制台,和它的对照篇,RXNE 中断加 64 字节环形缓冲
- **时间站五篇**:TIM 家族与确认式消抖、指定初始化器当模板实参、16 位 PSC 乘 16 位 ARR 的量程边界、NVIC 抢占等级怎么排、SysTick 时基
- **模式站加一篇**:日志组件的两种写法与两个观看面

十篇中英同步,libestdx 的 submodule 跟着往前走了一版。I2C 站和 F103 到 F407 那一站还是占位,后面继续。

## mini STL 实战(四):RingBuffer(#318)

固定容量的循环队列,系列里最短的一件容器。读写指针只增不减,判空判满一次减法出结果,2 的幂把取模变成一条位与,汇编实测三种取模的机器码。还讲了覆盖式 push 的 Census 配平,以及连续区间版析构在环形布局上漏掉的那半圈。配套 `code/volumn_codes/vol8-labs/ministl/stage2_ring_buffer/` 的 HANDBOOK,Vector 那一站补了 `move_if_noexcept` 的单测。

## 社区勘误与修正

- **reinterpret_cast 的边界**:@Melaine-iceberg 指出 float 经 reinterpret_cast 转 uint32_t 违反严格别名规则(#323)。卷一类型转换篇改成 std::bit_cast 的写法,并把 reinterpret_cast 什么时候能用、哪些是安全动作写了清楚(#324)
- **std::latch::arrive_and_wait 的原子性**:@Share1dpTr 反馈「递减加等待两步有原子性保证」的说法与标准不符(#328)。原文改成状态型等待的解释:计数只减不加、零是不可逆终态,所以不会错过唤醒(#330)。重写后第三关的「按协作需求选择工具」一篇沿用这个口径
- **decltype(auto) 转发的悬垂引用分析**:@FGTFH 反馈万能引用加 forward 加 decltype(auto) 的表述问题(#329),卷二完美转发篇的分析改对了(#331)
- **generate_reports 的 std::move 误用**:@sweetheartzj 指出 STL 常用模式实战演练的代码问题(#335),正文和 `code/examples/vol1/26_stl_patterns.cpp` 一起改(#336)
- **两处原样编译不过的示例**:@TianShuai-NUIST 两个 PR,友元成员函数示例的声明顺序(#332),枚举类型示例里 [[nodiscard]] 的位置(#337)。两处都附了 g++ -std=c++17 -Wall -Wextra -fsyntax-only 的前后对比,英文镜像同步改
- **const 基础篇修订**:@owollz4 的 2026.11.13 审查报告(#326)推动了卷一 const 基础篇的修订(#327):新增「引用初探」一节,const 与 constexpr 的分工拿数组大小当试金石,把「const 只承诺不许改,constexpr 把编译期写进语义」讲清楚
