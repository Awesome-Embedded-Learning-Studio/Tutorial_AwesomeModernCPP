# 富组件与文章改造大纲

本大纲规划两件事：教程站点的交互与富组件建设，以及现有交互手段接入各卷文章的顺序。对应 issue #325。

我们正在计划添加更多的富组件，底线要求是使用Typora等主流的 Markdown Reader的时候，仍然不会受到干扰和影响的阅读我们的教程。

同时，教程的深度优化也要同时推进。

## Current Assets

- 站点已有六种交互手段：在线运行卡（`OnlineCompilerDemo`，可同时展示 x86-64 与 ARM 汇编）、教学动画（`Anim`）、并发时间线（`ConcurrencyTimeline`）、mermaid 图、drawio 图、图片放大。
- 在线运行卡在 142 篇正文里使用，集中在卷一到卷五。汇编视图有 12 篇在用。教学动画卷二 30 个，卷八 18 个。
- 机械层基本干净：frontmatter 校验 1366 个文件零警告，内部链接全通，`check_quality.py` 零问题。粗体渲染残留 71 行，分布在 51 个文件。英文镜像过期 2 篇。

## Gaps

- 有 C++ 代码而没有运行卡的正文 422 篇。卷六、卷九、卷十、compilation 四处一张运行卡都没有。
- 212 篇正文含 40 行以上的代码块，读者只能一次读完。
- 128 篇有练习小节。现有的测验组件 `QuizProblem` 读取 `frontmatter.weeklyIssue`，只能用在每周一些题的页面，嵌不进普通文章。
- 239 篇讲内存布局、对齐、寄存器或栈帧，全部靠文字和静态图。
- `<details>` 折叠块全仓未使用。
- `CONTRIBUTING.md` 的「自定义 Vue 组件」一节只写了导航和参考文献两类，没有交互组件的用法。

## Scope

- 在范围内：新组件的建设，现有交互手段向各卷文章的接入，接入所需的示例文件与验证。
- 不在范围内：文章文风与结构的打磨。这部分由维护者随各卷自行安排。
- 底线：接入运行卡的示例必须能编译，正文贴出的输出必须与实际运行一致。

## Outline

### 一、准备

1. 站点主题的设计变量（颜色、间距、圆角）先确定，新组件依此实现。
2. `<details>` 折叠块在正文、深色模式、窄屏三种情形下的样式。
3. `CONTRIBUTING.md` 的「自定义 Vue 组件」补上运行卡、汇编视图、动画、折叠块的用法。
4. 清理 71 行粗体渲染残留，同步 2 篇过期的英文镜像。
5. 示例的验证步骤：编译通过，输出与正文逐字一致，才接入运行卡。

### 二、第一波组件

每个组件交付三样：组件文件，接入说明，一个用上了它的样例页。

1. 分步代码（StepThroughCode）：按步骤高亮一段代码，每一步配一句讲解。
2. 文内小测（InlineQuiz）：单选与猜输出，即时判定，进度保存在浏览器本地。
3. 内存布局图（MemoryLayout）：可悬停的字节图，显示偏移、大小与对齐。

接入说明是组件的接口。运行卡需要源文件路径、编译选项和一句说明。分步代码需要代码里的步骤标记和每一步的一句话。内存布局图需要写在 Markdown 里的一小段数据。

### 三、现有手段接入

1. 先猜再展开：输出和思考题的答案用 `<details>` 折叠，标题提示读者先猜。
2. 运行卡第一批：卷五、卷三、卷二里有代码而没有运行卡的文章。这三卷已有一半文章在用。
3. 运行卡第二批：卷四，卷八里 host 可跑的子域，卷九。卷九每个系列选取能独立运行的最小复现。
4. 汇编视图：性能与开销的断言处开启 x86-64 或 ARM 汇编。
5. 动画：每章选取一个有先后步骤的过程制作，产线见 `site/.vitepress/theme/components/animations/README.md`。

说明三点。卷一随重写推进，不单列。嵌入式板端代码不在浏览器里运行，不接运行卡，改配串口日志或动画。compilation 卷已完成，只接受勘误。

## Dependencies

- 第二部分的三个组件依赖第一部分第 1 项的设计变量。
- 运行卡与汇编视图的接入依赖示例的验证步骤。
- 先猜再展开依赖折叠块的样式。
- 运行卡第二批排在第一批之后。
- 其余各项互不依赖，可以并行。

- [ ] 三个新组件各有一个样例页在线上可用。
- [ ] 卷二到卷五、卷八的 host 子域、卷九里，有 C++ 代码而没有运行卡的文章降到 0。板端代码和多文件工程除外。

## 附二：现有机制

- 运行卡通过 Compiler Explorer 的接口执行，源码从仓库 main 分支读取。示例文件要先进入仓库，`run-options` 要写全编译标准。
- 教学动画由场景描述编译成 JSON 数据，文章里用 `<Anim id="…" />` 引用。

复查命令：

```bash
.venv/bin/python scripts/validate_frontmatter.py
.venv/bin/python scripts/check_links.py
.venv/bin/python scripts/check_quality.py documents/
pnpm exec tsx scripts/check_bold_rendering.ts
.venv/bin/python scripts/en_stale_scan.py
grep -rl '<OnlineCompilerDemo' documents --include='*.md' | grep -v '/en/' | grep -v 'index.md' | wc -l
```
