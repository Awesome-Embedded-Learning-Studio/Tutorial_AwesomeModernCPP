# E7 IPC 选型矩阵(E1–E6 的收束素材)

一句话总纲:**先问「数据要不要过内核」,再问「两边是什么关系」**。要吞吐、数据成块成流,尽量不过内核(shm);要边界和优先级、量不大,选 mq;父子一趟活,pipe 最省事;不相干进程、单向流,FIFO;传的不是数据而是「访问权」,SCM_RIGHTS。

## 适用矩阵

| 通道 | 进程关系 | 数据形态 | 同步 | 方向 | 定位一句话(实测锚点) |
|---|---|---|---|---|---|
| pipe(E1/E2) | 只认亲缘:fork 前建好,fd 靠继承;fd 想传人另说(见 SCM_RIGHTS) | 字节流,无边界,默认 64 KiB(16 页)内核环形缓冲,F_SETPIPE_SZ 可调 | 内核自带流控:写满阻塞(65536 字节整)、读空等待、写端全关 EOF、读端全关 SIGPIPE | 单向,双向要两根 | 「fork+exec 管道过滤器」的机制地基(E2 dup2 工程化) |
| FIFO(E3) | 无关进程靠路径名相会(open 双向互等) | 字节流,与 pipe 同一套内核缓冲(实测同 64 KiB) | 同 pipe;多写者单读者时 ≤PIPE_BUF(4096)的写入内核保原子,>PIPE_BUF 会撕(实测概率性撕裂) | 单向 | pipe 的命名版:同一个内核对象,加了目录项当「会面地点」 |
| POSIX mq(E4) | 无关进程靠 /dev/mqueue 里的名字(与 shm 的 /dev/shm 同构) | 定长消息:边界保留、有优先级(高者先出、同级 FIFO);非特权上限 队列深 10、单条 8192 | 内核自带满/空阻塞;mq_notify 能主动递信号(一次性注册) | 单向(收发两端各持 mqd) | 边界与优先级是免费的,吞吐是四族里垫底的(mq@1024 中位 1245 MiB/s) |
| POSIX sem(E5) | 命名 sem_open 跨进程;匿名 sem_init(pshared=1) 贴着共享内存走 | 不承载数据,只有计数(名额/闸门) | 它本身就是同步原语 | —— | 给别的通道配「名额」:两名额三进程,第三个干等 699.4 ms 放行 |
| shm + 自选通道(Lmem03) | 无关进程靠 /dev/shm 名字 | 裸内存,想是啥是啥(环形队列、结构体、大数组) | 不带,自己上(Lmem03 E2 无同步丢 18.6% 更新的实证) | 双向 | 吞吐王:同 1 MiB 中位 7304 MiB/s,代价是同步全自理 |
| SCM_RIGHTS(E6) | 任意已连好的 unix socket 两端(可跨亲缘) | 传的不是字节,是「一个打开的文件」:接收方拿到自己 fd 表里的新编号,与发送方共享同一打开文件描述(pos 共享) | 无缓冲,一寄一收 | 单向(反向可再传一次) | 不搬数据搬访问权:发送方 close 后接收方照用,是引用不是移交 |

## 怎么选(决策序)

1. **先看数据量级与延迟预算**:大流量、热路径 → shm + SPSC 环形(Lmem03 招牌),7304 MiB/s 对 pipe 的 2349、mq 的 1245(1024 B 口径)。低频、小消息、控制面 → mq 或 pipe 都绰绰有余,选顺手的。
2. **再看两边关系**:亲缘(fork/exec 链)→ pipe 起步,连名字都不用起;不相干进程 → FIFO(字节流)或 mq(消息+优先级);要双向就 mq/socket,别硬掰两根管道。
3. **再看要不要消息语义**:要边界、要优先级、要「队里压了几条」(mq_curmsgs)→ mq;自己拆包(定长/长度前缀/分隔符)不心疼 → pipe/FIFO 省下一切。
4. **要不要同步原语而不搬数据** → sem(计数名额)或互斥锁(Lmem03);**要传的其实是「访问权」**(比如让另一进程读你打开的文件/设备/连接)→ SCM_RIGHTS,别把内容读出来再写回去。
5. **多写者共用一条通道** → 守住单条消息 ≤PIPE_BUF(4096);消息更大就必须自己加应用层分割与同步,或者换 mq/socket。

## 吞吐对照(同机同口径:1 MiB、逐块校验、3 轮取中位)

| 通道 | 粒度 | 中位 MiB/s | 来源 |
|---|---|---|---|
| shm SPSC 环形队列 | 1024 B × 1024 | 7304 | Lmem03 E5(引用) |
| pipe | 1024 B × 1024 | 2349 | Lmem03 E5(引用) |
| POSIX mq(队列深 10) | 1024 B × 1024 | 1245 | 本篇 E4d |
| POSIX mq(队列深 10) | 8192 B × 128 | 3179 | 本篇 E4d |
| pipe | 8192 B × 128 | 4753 | 本篇 E4d |

注:WSL2 上逐轮波动可达 ±40%,绝对值仅供量级参考;**排序**在所有轮次里稳定:shm ≫ pipe ≥ mq(同尺寸),消息越大 mq 与 pipe 的差距越小(系统调用次数被摊薄)。
