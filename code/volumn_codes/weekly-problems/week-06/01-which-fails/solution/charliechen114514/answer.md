**思路**:

编不过的是第 3 句 `int c = Fruit::PEAR;`。笔者拿 GCC 16.2.1、`-std=c++20` 试过,报错原文是:

```text
error: cannot convert 'Fruit' to 'int' in initialization
```

咱们把四句挨个过一遍,看它们各自走的是哪条路。老式 `enum` 的枚举值,一出身就能当整数用,`RED` 直接塞给 int,第 1 句没事;第 4 句 `Color d = GREEN;` 两边都是 Color,类型内部赋值,更没事。enum class(C++11 引入,也叫强类型枚举)把那条隐式通道关了:枚举值只认自己这个类型,不许和整数悄悄互转。第 3 句想把 `Fruit::PEAR` 塞给 int,被拦下的就是它。

那 enum class 的枚举值就变不成整数了吗?能,得您亲手写明:显式 `static_cast<int>`。第 2 句就是这么写的,四句里它反而最稳。这也是引入 enum class 的用意——转换必须经您的手过一道,编译器不再替您自作主张。

**排错**:

选岔了?最常见的是挑了第 2 句:`static_cast<int>` 看着就像个危险操作,直觉上像是它在惹事。方向反了,它恰恰是被允许的正规通道:四个选项里,显式转换的那句最没嫌疑。另外别盯着第 4 句怀疑:那里没有跨类型,`GREEN` 本来就是 Color,谈不上编不过。
