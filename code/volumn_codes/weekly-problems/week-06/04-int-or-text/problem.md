每行一个词,读到 EOF 为止。整行恰好是一个十进制整数(开头最多带一个负号,其余全是数字),就输出一行 `int <数值>`;不是整数,就输出一行 `text <原词>`。

几个例子:输入 `42`,输出 `int 42`;输入 `-3`,输出 `int -3`;输入 `007`,输出 `int 7`(前导零不影响,数值就是 7);输入 `3a`,输出 `text 3a`;单独一个 `-`,后面没有数字,不算整数,输出 `text -`——这五个全在判题用例里。空行同样过不了这道判定,照 text 走。您手里是 `fgets`、`isdigit`、`atoi` 这些最熟的工具,按行读,一个字符一个字符判。
