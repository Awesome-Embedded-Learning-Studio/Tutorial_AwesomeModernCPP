压轴题,笔者围绕《C和指针》第 7 章自命题:这一次,轮到您来实现 printf 本身。

原型固定:

```cpp
int mini_sprintf(char* out, const char* fmt, ...);
```

约定:缓冲区 `out` 足够大,不用考虑截断,返回值是写入的字符数,不含结尾的 `'\0'`。支持四种转换:

- `%d`:参数为 `int`,按十进制输出,负数带负号。
- `%s`:参数为 `const char*`,指向 NUL 结尾的字符串,整串复制进 `out`。
- `%c`:参数为 `char`,输出这一个字符。
- `%%`:不取参数,输出一个 `%`。

`fmt` 里的其余字符都是普通文本,原样复制过去。题目起始代码(starter.cpp)的上半部有一段判题辅助 `text_eq`(比对两个 NUL 结尾的字符串),请勿改动。判题程序拿它核对缓冲区内容,返回值另有断言直接比。

判题共八条用例,平常规矩与刁钻的都在里面:纯文本、`%d` 配 42、0、`INT_MIN`(`<climits>` 里最小的 int,-2147483648)、-7,`%s` 与 `%%` 混排,`%c%c%c`,以及空 fmt(此时返回 0,`out[0]` 必须是 `'\0'`)。
