**思路**:

这题您来当 printf 的实现者。骨架和 max_list 一样,围着 va_list、va_start、va_arg、va_end 这四件转,区别在角色:那题您从参数列表里读数,这题您定规则,fmt 里每个字符告诉您下一步做什么。对着 solution.cpp 看:

```cpp
    char* w = out; // 写游标:下一个字符落在哪
    for (const char* p = fmt; *p != '\0'; ++p) {
        if (*p != '%') { // 普通字符:直接抄
            *w++ = *p;
            continue;
        }
        ++p; // 跳过 %,看转换符
```

w 是写游标,永远指着「下一个字符落在哪」。p 扫 fmt,普通字符直接复制,碰上 `%` 就先加一,看转换符走哪一路。收尾是 `*w = '\0'` 加 `return (int)(w - out)`:前者补结尾,后者用游标减起点数出写了几个字符,自然不含 `'\0'`。

这份实现有三处最容易翻车的地方,两处在 `%d` 支,一处在 `%c`:

```cpp
            int v = va_arg(args, int);
            unsigned u = (unsigned)v;       // INT_MIN 直接取反会溢出,走 unsigned
            if (v < 0) {
                *w++ = '-';
                u = 0u - u;
            }
            char tmp[12]; // int 最多 11 位(含负号),倒着存
            int n = 0;
            do {          // do-while:值为 0 也要打出那一个 '0'
                tmp[n++] = (char)('0' + u % 10);
                u /= 10;
            } while (u != 0);
            while (n > 0)
                *w++ = tmp[--n]; // 倒序回填
```

第一处是值为 0。数字逐位「%10 取余、/10 去位」,先取余再除,循环必须用 do-while:值为 0 也要打出那一个 `'0'`,写成 `while (u != 0)` 的话循环体一次都不进,一位数字都写不进 tmp。第二处是 INT_MIN。最小的 int 是 -2147483648,对它取负,数学上要 2147483648,比 INT_MAX 大一截,直接 `-v` 是未定义行为。走 unsigned 承接:先 `(unsigned)v`,负号单独写,数值用 `0u - u` 折算,一路无符号,不会再溢出。判题用例用的是 INT_MIN 宏。顺带说一句,要在用例里直接写 `-2147483648` 字面量反倒不行,那个字面量的类型不再是 int,在本站的 64 位 Linux 判题环境里是 long,和 `va_arg(args, int)` 对不上号。

第三处在 `%c`:

```cpp
        case 'c': // 字符经默认实参提升变成 int,取出来再转回 char
            *w++ = (char)va_arg(args, int);
```

字符经过可变参数列表会被提升成 int,取参数就得按 int 取,取出来再转回 char。这正好接上 max_list 那条线:va_arg 按您报的类型读内存,您报 char 它就按 char 的宽度读,实参实际是 int 宽的,读出来就串位了。`%s` 和 `%%` 不会翻车:一个指针直接复制到 NUL,一个落一个 `%`。

**排错**:

还是不通过?把判题用例逐条对过去。`%d` 配 0 那条,返回值该是 1、缓冲区该是 `"0"`,您要是得到 0 和空串,就是取数字写成了 while 版。INT_MIN 那条输出该是 11 个字符的 `-2147483648`,对不上就查负数分支走没走 unsigned。空 fmt 那条最刁:判题用例里的缓冲区 `b`(传给 `out` 的那个数组)先给 `b[0]` 塞了 `'x'`,断言返回 0 且 `b[0]` 是 `'\0'`,收尾那行 `*w = '\0'` 漏了的话,别处全对,就这一条把您拦下来。
