**思路**:

下面的参考答案是投稿人 owollz4 的原稿,思路由笔者代述。

gcd 的老办法是辗转相除:大数除以小数,余数替掉大数,余数变成 0 时另一个参数就是答案。对着 solution.cpp 看,他的写法先把两个参数的大小关系分清楚,再分头递归:

```cpp
    if (n > m)
    {
        if (n % m == 0)
            return m;
        return gcd(m, n % m);
    }
```

n 大就走这支:n 能整除 m,答案直接是 m,否则拿「m 和余数」再递归一轮。n 小的那支完全对称,两个参数一样大,落到最后的 `return n`。开头还有一个防御分支:

```cpp
    if (n <= 0 || m <= 0)
        return -1;
```

约定两个参数都是正整数,这个分支管的是约定之外的输入,判题数据碰不到它,留着不亏。

有意思的对照是更朴素的写法,一步到位:

```cpp
return b == 0 ? a : gcd(b, a % b);
```

它不预先比较大小,因为辗转相除第一轮就把两个数换到了该在的位置:`gcd(18, 12)` 进去,下一轮就是 `gcd(12, 6)`。两种写法笔者都拿六组判题断言跑过,全过。教学场景笔者更愿意摆 owollz4 这版,每个分支都摆在明面上,您可以顺着念出声。朴素版短,您写熟了之后顺手就是它。
