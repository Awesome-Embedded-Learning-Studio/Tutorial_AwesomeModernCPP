8×8 的棋盘上放 8 个皇后,让任何一个都攻击不到其余皇后——皇后横、竖、斜三条线都能吃子。这就是流传已久的**八皇后问题**:一共有多少种合法摆法?您的任务是写程序把所有答案找出来,数出总数。

把这题做成函数:`int count_solutions(int n)` 返回 n×n 棋盘上放 n 个皇后的解的总数,主目标是 `n = 8`。**必须用回溯(递归)搜索求解,不许打表、不许硬编码各个 n 的答案**——测试数据里那些数字都是公开可查的,背下来就没意思了。

参考量级:`count_solutions(4)` 应返回 `2`,`count_solutions(8)` 应返回 `92`。
