实现一个字符串复制函数,原型固定:

```cpp
void copy_n( char dst[], char src[], int n );
```

把字符串从 `src` 复制到 `dst`,但要求苛刻:**必须正好复制 n 个字符到 `dst`,不能多,也不能少**。

- `src` 的长度小于 `n`:复制完 `src` 的全部字符后,用 `'\0'` 把 `dst` 剩下的位置填满,凑够 n 个;
- `src` 的长度大于等于 `n`:复制前 n 个字符就停。此时 `dst` **不保证**以 `'\0'` 结尾——这是允许的,别多写一格。

也就是说,`copy_n` 只对 `dst[0]` 到 `dst[n-1]` 这 n 格负责,`src` 长多少短多少都不改变这个边界。(注:NUL 字符就是 `'\0'`。)

示例:`src = "abc"`、`n = 5`,那么 `dst` 的前五格依次是 `'a' 'b' 'c' '\0' '\0'`;`src = "abcdef"`、`n = 3`,`dst` 前三格是 `'a' 'b' 'c'`,后面的格子是什么不用管。
