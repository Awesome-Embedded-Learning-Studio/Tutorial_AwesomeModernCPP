一个已经从小到大排序的数组里,**平台(plateau)**是连续的一串值相同的元素,并且这一串不能再向两边延伸。比如在 `1 2 2 3 3 3 4 5 5 6` 中,`1`、`2-2`、`3-3-3`、`4`、`5-5`、`6` 都是平台,其中最长的是 `3-3-3`。

编写程序:读入数组,把其中**最长的平台**找出来。

输入:第一行一个整数 `n`,第二行 `n` 个已从小到大排序的整数(`1 <= n`)。输出:一个整数,最长平台的**长度**。示例输入对应上面的数组,最长平台 `3-3-3` 的长度是 `3`,输出 `3`——注意别把平台的「值」和「长度」搞混,书里这个例子两者恰好都是 3。

提示:数组**已经排好序**,相等的值必然挨在一起,这个前提就是解题的钥匙。
