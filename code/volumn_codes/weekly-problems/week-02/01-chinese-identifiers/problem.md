C++ 的标准其实允许标识符里出现非 ASCII 字符,主流编译器也真的支持——下面这段代码在 GCC(`-std=c++23`)里原样编过,输出 `1` 和 `42`:

```cpp
#include <cstdio>

int 变量 = 1;

int 计算(int 输入) { return 输入 * 2; }

int main() { std::printf("%d %d\n", 变量, 计算(21)); }
```

语言都点头了,可在真实的开发实践里,几乎没有团队建议用中文命名变量和函数。这是为什么?

先自己想出一两条站得住的理由,再展开看参考答案。这是思考题,没有唯一解——能自圆其说、说到点子上,就算过关。
