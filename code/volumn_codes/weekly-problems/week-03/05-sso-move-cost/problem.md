先把这段代码在心里过一遍:

```cpp
std::string s = "hello world";  // 11 个字符
std::string t = std::move(s);
```

三问,一问比一问深:

一问——这行执行完,`s` 处在什么状态?它还能用吗?

二问——教科书说 `std::string` 的移动构造是「偷指针,常数时间」:这行也是常数时间吗?

三问——把 `"hello world"` 换成 500 个字符的长串,再来一遍,第二问的答案变了吗?为什么同一行代码,长串和短串的行为不一样?

这是思考题,不判分。先自己猜,再去 [Godbolt](https://godbolt.org) 把两个版本各编译一遍——看移动构造那一趟到底生成了什么代码,再回来对照参考答案。
