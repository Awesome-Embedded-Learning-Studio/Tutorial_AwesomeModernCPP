看到「相邻数字差」是不是第一反应想转字符串或者写循环？别急，递归的老规矩还是那套：把大问题拆成小问题。先问问自己：嘿！咋把 `n` 的相邻差算出来，又能让规模变小呢？答案就是从最后两位下手。最后一位是 `n % 10`，倒数第二位是 `(n / 10) % 10`，它俩的绝对差就是当前这一对的贡献。剩下的呢？把最后一位砍掉，也就是 `n / 10`，继续递归。这不就拆小了嘛！

依旧边界思考。如果 `n < 10`，只剩一位，压根没有相邻对，返回 0。干净利落。

对着代码看：

```cpp
#include <cstdlib>

int digit_distance(int n) {
    if (n < 10){ 
        return 0;
    }  // 只剩一位:没有相邻对
    return std::abs(n % 10 - (n / 10) % 10) + digit_distance(n / 10);
}
```

`std::abs(n % 10 - (n / 10) % 10) + digit_distance(n / 10);`是精髓。来，一点一点看~。

`n % 10` 是最后一位，`(n / 10) % 10` 是倒数第二位，`std::abs` 取它俩的绝对差，然后加上 `digit_distance(n / 10)`——也就是把最后一位扔掉之后的答案。整个函数没有一处循环，一次递归只处理一对相邻数字，从右往左一路推过去，不重不漏。

比如 `n = 1234`：
- `|4 - 3| = 1`，加上 `digit_distance(123)`
- `|3 - 2| = 1`，加上 `digit_distance(12)`
- `|2 - 1| = 1`，加上 `digit_distance(1)`
- `digit_distance(1)` 返回 0
最后就是 `1 + 1 + 1 + 0 = 3`。

完事拉！
